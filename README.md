# ARGO CD (ATS061)

Certified Argo Project Associate (CAPA): ARGO CD, worth 34% of the official curriculum. This course belongs to ATP012.

Developed reading explains mechanisms, responsible components, examples and limits. Every section has an introduction and every module closes with a summary. Reusable YAML checks contain 5–15 questions per bank. Technical content remains draft. Private playgrounds, draft graded labs, section capstones and a final domain quiz are included.
