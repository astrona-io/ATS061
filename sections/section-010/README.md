# Understand Argo CD Fundamentals

This section covers understand Argo CD Fundamentals. It develops argo CD Desired State And Reconciliation through mechanisms, examples, prerequisites and failure reasoning.

Read the module goals, teaching and closing summary in order. YAML checks are indexed separately and appear after designated summaries. Larger domains include an intermediate checkpoint before the final review.

## Learning Outcomes

- Explain declarative desired state and live-state comparison.
- Distinguish repository rendering from cluster application.
- Separate sync status from resource health.
- Identify controller, repository and access dependencies.
