# Summary

Reconciliation patterns define how desired state is discovered, compared and applied. Refresh, sync and self-heal have distinct effects, while generated Applications add another ownership layer.

Ignore rules can reduce irrelevant differences but can also hide meaningful drift. Review field ownership and durable source decisions so multiple controllers cooperate rather than overwrite each other or conceal an unintended change.
