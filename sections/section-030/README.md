# Use Argo CD Application

This section covers use Argo CD Application. It develops application Source, Destination And Project Boundaries through mechanisms, examples, prerequisites and failure reasoning.

Read the module goals, teaching and closing summary in order. YAML checks are indexed separately and appear after designated summaries. Larger domains include an intermediate checkpoint before the final review.

## Learning Outcomes

- Read an Application's source, destination and project relationships.
- Explain revision, path, namespace and cluster identity.
- Distinguish AppProject restrictions from destination RBAC.
- Evaluate tracking, status and deletion lifecycle.
